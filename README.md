# Cuaderno Cornell

Libreta digital con el Método Cornell (palabras clave · notas · resumen), pensada para estudiantes: funciona sin conexión, guarda sola y permite respaldo completo de los apuntes.

**v2:** nombre corregido, buscador de apuntes, orden por edición reciente, duplicar hojas, respaldo exportable/importable (JSON), temas de color rápidos, conteo de palabras y medidor de hoja completa, ayuda del método en 5 pasos, impresión limpia, PDF sin depender de internet (librería local) e iconos optimizados. Conserva los apuntes guardados con la v1.
